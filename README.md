# my-portfolio
MyPortfolio - A beginner-friendly personal portfolio website built with HTML, CSS, and JavaScript. Showcases About, Skills, and Contact sections.

This is a simple one-page personal portfolio website created as part of a Web Developer assignment.

## 🔧 Technologies Used
- HTML
- CSS
- JavaScript

## 📄 Features
- One-page layout
- About, Skills, and Contact sections
- Responsive design (desktop & mobile)
- Clean and beginner-friendly code

## ▶️ How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder in your system.
3. Make sure Python is installed.
4. Run the following command in the project folder:

   python -m http.server 8000

5. Open your browser and visit:

   http://localhost:8000  
   or  
   http://192.168.x.x:8000 (local network IP)

## 🌐 Local Hosting
The website runs on a local server using Python’s built-in HTTP server and is accessible via the local IP address.
